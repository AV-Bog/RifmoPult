# RifmoPult 📝

*Помощник для написания стихов — мобильный редактор для Android*

**RifmoPult** — приложение для стихосложения: подбирает рифмы прямо в редакторе, считает слоги, разбирает стихотворный размер и расставляет ударения. Написано на Kotlin, работает офлайн для всего, кроме подбора рифм и ударений (они идут через внешние API).

## 🔍 Ключевые возможности

- ✍️ **Редактор стихов** — список заметок и экран редактирования, авто- и ручное сохранение, дата последнего изменения, экспорт чистого текста.
- 🔍 **Мгновенный подбор рифм**: выделите слово → «Рифма к слову» → до 100 вариантов с учётом ударения. Источник — [rifmovka.ru](https://rifmovka.ru), разбор ответа через JSoup.
- 🖱️ **Перетаскивание рифм** — подходящее слово тянется из панели прямо в текст.
- 🔤 **Подсчёт слогов** по гласным, с отображением в конце каждой строки (включается в настройках).
- 🎯 **Анализ стихотворного размера** — ямб, хорей и другие размеры с подсчётом количества сбоев.
- 🔤 **Ударения** — автоматическая расстановка через API [Morpher.ru](https://morpher.ru) с возможностью ручного редактирования.
- 🎨 **Визуальное выделение рифм** — рифмующиеся строки подсвечиваются одинаково, нерифмующиеся помечаются серым кружком.
- 💾 **Локальное хранение** — Room/SQLite, данные не покидают устройство.

## 🛠 Сборка и запуск (для разработчиков и проверяющих)

Пользователю приложение не нужно собирать — оно ставится из [RuStore](https://www.rustore.ru/catalog/app/com.example.rifmopult). Этот раздел — для тех, кто читает код: собрать проект из исходников, прогнать тесты, проверить, что собранная сборка соответствует опубликованной, или внести правку.

### Требования

- **JDK 17** (проект собран на AGP 8.13.2, Kotlin 2.0.21)
- **Android SDK** с платформой `android-36` и build-tools (проще всего — через Android Studio)
- Git

### Пошагово

```bash
# 1. Клонировать репозиторий
git clone https://github.com/AV-Bog/RifmoPult.git
cd RifmoPult/RifmoPult          # корень Gradle-проекта лежит в подкаталоге RifmoPult/

# 2. Указать путь к Android SDK (файл в .gitignore, в репозиторий не попадает)
echo "sdk.dir=$HOME/Library/Android/sdk" > local.properties
#   Linux/Windows: sdk.dir=/home/user/Android/Sdk  или  sdk.dir=C\:\\Users\\user\\AppData\\Local\\Android\\Sdk

# 3. Собрать debug-сборку
./gradlew assembleDebug

# 4. Установить на подключённое устройство или эмулятор
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

Альтернатива: открыть каталог `RifmoPult/` в Android Studio и нажать Run — SDK подхватится из IDE.

**Про ключ AppMetrica.** В `local.properties` можно указать `APPMETRICA_API_KEY=<ключ>`; при сборке он подставляется в `BuildConfig`. Если строки нет, подставляется пустая строка — приложение собирается и запускается, аналитика просто не отправляет события.

### Сборка release (для публикации в RuStore)

```bash
./gradlew assembleRelease
```

Сейчас release-сборка подписывается debug-ключом — так настроено в `app/build.gradle.kts`, чтобы APK собирался без секретов в репозитории. Для публикации в магазине нужен собственный keystore: он лежит локально и в репозиторий не попадает (`.gitignore`), путь и пароли передаются через `local.properties` / переменные окружения.

## ✅ Тесты

В проекте 12 модульных тестов JUnit в трёх классах — они покрывают логику, которая раньше ломалась чаще всего:

| Класс | Что проверяет |
|---|---|
| `NoteEditLogicTest` | подсчёт слогов по русским гласным, снятие маркеров слогов (`·N`), распознавание пунктуации |
| `NoteSaveLogicTest` | нужно ли сохранять заметку: изменённый заголовок, изменённый текст, сравнение без маркеров слогов, различия только в пробелах |
| `PoemUpdateTest` | обновление даты последнего изменения только при реальном изменении текста |

Запуск:

```bash
./gradlew testDebugUnitTest
```

HTML-отчёт: `app/build/reports/tests/testDebugUnitTest/index.html`.

Инструментальные тесты (`app/src/androidTest`) требуют устройства или эмулятора: `./gradlew connectedDebugAndroidTest`.

## 📦 Технологии

- **Язык**: Kotlin 2.0.21
- **Архитектура**: двухслойная (View + Model) с выделенным слоем доступа к данным — Repository поверх Room DAO; подробнее в [ARCHITECTURE.md](ARCHITECTURE.md)
- **Библиотеки**: Room (SQLite), Ktor (сеть), JSoup (разбор HTML), Kotlin Coroutines, ViewBinding, Flexbox, Material Components, AppMetrica (аналитика)
- **Сборка**: Gradle 8.13 (Kotlin DSL, version catalog)

# Rifmopult 📝✨
*Помощник для написания стихов*

**Rifmopult** — это удобный инструмент для стихосложения, разработанный специально для Android. Приложение помогает подбирать рифмы, автоматически оформляет стихи для отправки и надёжно сохраняет всё написанное — чтобы вы никогда не теряли вдохновение.

> «Чтобы подобрать рифму, достаточно выделить слово — и сотня вариантов уже у вас под рукой.»

## 🔍 Ключевые возможности

- ✍️ **Помощник для написания стихов** — всё, что нужно поэту, в одном месте.
- 🔤 **Автоматический подсчёт слогов** в каждой строке.  
  → Включается в **Настройках** → «Показывать подсчёт слогов».
- 🎯 **Анализ стихотворного размера** — определение ямба, хорея и других размеров с отображением количества сбоев в стихе.
- 🔤 **Умные ударения** — автоматическая расстановка ударений через API Morpher.ru с возможностью ручного редактирования.
- 🎨 **Визуальное выделение рифм** — рифмующиеся строки подсвечиваются одинаково, а нерифмующиеся строки отмечаются серым кружком.  
- 🔍 **Мгновенный подбор рифм**: выделите слово → «Рифма к слову» → получите до 100 вариантов.
- 🖱️ **Перетаскивание рифм**: просто потяните подходящее слово из панели прямо в текст!
- 📤 **Однокнопочная отправка**: нажмите кнопку в правом верхнем углу — и ваш стих готов к публикации или пересылке.
- 📅 **Дата последнего изменения** — в редакторе отображается точное время и дата последнего сохранения.
- 📋 **Полное превью стихотворений в списке** — даже длинные произведения отображаются целиком, без обрезки.
- 💾 **Авто- и ручное сохранение** — вы никогда не потеряете ни строчки.

## 🌐 Источник рифм

Rifmopult использует мощный онлайн-сервис **[rifmovka.ru]([https://rifmovka.ru])**, который:
- подбирает рифмы с учётом **ударения и звучания**,
- показывает **точные рифмы в начале списка**,
- умеет искать **ассонансы** (созвучие по гласным),
- фильтрует **редкие и неудачные варианты**,
- оптимизирован для **мобильных устройств**.
